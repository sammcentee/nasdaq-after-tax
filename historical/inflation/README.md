# Irish CPI contribution inputs

Source: Central Statistics Office, Ireland, [CPM02: Consumer Price Index by Selected Base Reference Period](https://data.cso.ie/table/CPM02). The calculation uses the national all-items CPI, with December 2006=100 throughout, rather than HICP. The unchanged reference base already existed when this study began.

`irish_cpi.csv` contains the 16 August observations needed for payments from September 2010 through August 2026, with each original official release date and URL. `provenance.json` records source hashes, the exact selection, release-date evidence and cross-checks. `cpm02_snapshot.json` is the unmodified official API response; observations beyond August 2025 are excluded from the calculation.

The first September payment is €1,000. At each following September payment, set the monthly amount to €1,000 × that August's CPI / August 2010 CPI, and hold that amount through the following August. Both inflation and deflation apply. This is an anniversary-month review, so a September trading date before the literal 30 September anniversary still reviews the contribution. No annual percentage rate or previous year's rounded payment is compounded. Retain the published index precision and round only the final payment to cents, half up.

The CPI release must precede the actual September review date strictly; a release on the same calendar day is conservatively rejected. All 16 actual release dates are available, so no assumed publication lag is needed. Unsupported dates or a review before publication fail rather than silently selecting a different month. August 2025 was published on 11 September 2025 and is the final observation used; no 2026 inflation estimate is required.

The indices come from a current official snapshot with historical publication dates, not an archived API vintage. CSO's [CPI quality report, section 19.2](https://www.cso.ie/en/media/csoie/methods/consumerpriceindex/Consumer_Price_Index_SIMS_2023_updated.pdf) states that national CPI is not revised. Fifteen archived monthly release tables were checked against the snapshot in their then-published bases; the August 2022 headline release supplies inflation rates without an index table. The post-2016 headline tables do not print the December 2006 base, whose continuity therefore relies on official CPM02 and the non-revision policy. CSO publishes these indices to one decimal place; the schedule does not invent greater source precision. Ratios of rounded indices can differ slightly from published percentage changes.
